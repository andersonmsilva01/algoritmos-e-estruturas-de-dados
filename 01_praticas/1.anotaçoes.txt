REGRAS DO SWITCH

1. O switch compara a variável com valores exatos e constantes nunca com condições ou intervalos. 

2. Só funciona com int e char.

3. Default vazio é erro de sintaxe, o compilador exige pelo menos uma instrução (um break;), se a cadeia de condições cobrir todos os casos, nem precisa de default.

Regra para gravar: 

+ Intervalos ("entre X e Y") → use if / else if / else. 

+ Valores exatos e discretos (menu 1, 2, 3) → switch é adequado. Aqui a ferramenta certa é a cadeia de ifs.

REGRAS DO CHAR

1. Um char ocupa 1 byte e guarda um único caractere: 'a', 'x', '7'.

2. Uma letra: só	char + aspas simples

3. Uma palavra:	ponteiro para char (const char *) + aspas duplas

ESTRUTURAS DE REPETIÇÃO

1. Use for quando o número de iterações é conhecido.

2. Use while quando a condição de parada depende de uma entrada ou evento.

3. Use do-while quando o bloco deve executar ao menos uma vez

- nao da para declarar var dentro da condicao do while igual no for
- mas da ter multiplas condicoes logicas, com var já declaradas

FUNCOES

Combinações possíveis de retorno e parâmetros em funções C:

Retorno = o que a função devolve (ou void se não devolve nada) 

Parâmetros = o que a função recebe de entrada

As 4 combinações:

1. void sem parâmetros → não recebe nada, não retorna nada
void saudacao(void) { printf("Olá\n"); }

2. void com parâmetros → recebe dados, mas não retorna nada
void exibirTabuada(int n) { /* imprime a tabuada */ }

3. Tipo específico com parâmetros → recebe dados e retorna um valor
int somar(int a, int b) { return a + b; }

4. Tipo específico sem parâmetros → não recebe nada, mas retorna um valor
int idadeAtual(void) { return 20; }

LOOPS

maior e menor numero
#include <stdio.h>

int main() {
    int n, x, menor, maior;

    printf("Digite quantos numeros serao comparados:\n");
    scanf("%d", &n);

    printf("Digite o primeiro numero:\n");
    scanf("%d", &x);

    menor = x;
    maior = x;

    for (int i = 1; i < n; i++) {
        printf("Digite o proximo numero:\n");
        scanf("%d", &x);

        if (x < menor) {
            menor = x;
        }

        if (x > maior) {
            maior = x;
        }
    }

    printf("Menor de todos: %d\n", menor);
    printf("Maior de todos: %d\n", maior);

    return 0;
}
