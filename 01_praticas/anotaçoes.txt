REGRAS DO SWITCH

1. O switch compara a variável com valores exatos e constantes nunca com condições ou intervalos. 

2. Só funciona com int e char.

3. Default vazio é erro de sintaxe, o compilador exige pelo menos uma instrução (um break;), se a cadeia de condições cobrir todos os casos, nem precisa de default.

Regra para gravar: 

+ Intervalos ("entre X e Y") → use if / else if / else. 

+ Valores exatos e discretos (menu 1, 2, 3) → switch é adequado. Aqui a ferramenta certa é a cadeia de ifs.

---------------------------------------------------------------------
---------------------------------------------------------------------
REGRAS DO CHAR

1. Um char ocupa 1 byte e guarda um único caractere: 'a', 'x', '7'.

2. Uma letra: só	char + aspas simples

3. Uma palavra:	ponteiro para char (const char *) + aspas duplas


---------------------------------------------------------------------
---------------------------------------------------------------------
ESTRUTURAS DE REPETIÇÃO

1. Use for quando o número de iterações é conhecido.

2. Use while quando a condição de parada depende de uma entrada ou evento.

3. Use do-while quando o bloco deve executar ao menos uma vez

- nao da para declarar var dentro da condicao do while igual no for
- mas da ter multiplas condicoes logicas, com var já declaradas
